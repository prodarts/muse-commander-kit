# 司令塔セットアップ

## 進め方

構築手順の正本は `docs/setup-full.md`。このスキルは、その手順を対話しながら進めるための入口。
パスの基準は、このキットのリポジトリ全体を作業場所に取得した状態。リポジトリを取得できない環境では、構築を始めず、その旨を本人に伝える。

1. まず本人に導入範囲を確認する（README の構成パターン A〜D）
2. `docs/setup-full.md` のフェーズを、選んだパターンに必要な分だけ順に実行する。必要なフェーズは飛ばさない
3. 本人操作と付いた手順（ログイン、鍵の承認など）は、やり方を案内して本人の実行を待ち、結果を確認してから次へ進む
4. 各フェーズの終わりに、できたものを本人に見せて確認を取る
5. 完了条件はパターン別。A はフェーズ1の検証が通れば完了。B〜D はフェーズ4のチェックリストが全部通ったら構築完了を宣言する

## 絶対に守ること

- 鍵・パスワード・トークンをチャットで受け取らない。本人の端末の中だけで扱う
- 外部への行動（送信・投稿・支払い・削除・公開）は、本人の最終確認なしに実行しない
- 裁定台帳は自動で書き換えない。本人が承認したルールだけを入れる
- 部下AIへの派遣は新規セッションが基本。再開は `docs/session-rule.md` の条件を全部満たすときだけ、セッションID明示で
